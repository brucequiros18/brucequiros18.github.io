Codara

05 / 05

An interactive coding game that teaches programming through challenges, puzzles, and game-like levels designed for beginners.

Game Development · Python · Flutter

About this project

Codara turns programming education into a game. Learners solve challenges, puzzles, and game-like levels that teach the fundamentals of code — one concept at a time.

The game engine is built with Python for the challenge logic, while Flutter delivers a polished cross-platform experience for the learner-facing screens.

Progression is level-based with immediate feedback, so beginners build confidence while learning real programming concepts.

Highlights

  • Level-based progression with instant feedback
  • Python challenge engine + Flutter UI
  • Designed for absolute beginners
