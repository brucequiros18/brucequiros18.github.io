SeekRet

02 / 05

A mobile application for lost-and-found management with interactive maps, secure authentication, and social media-inspired features.

Mobile Application · Flutter · Firebase

About this project

SeekRet is a lost-and-found mobile application that connects people who lose items with those who find them. Built with Flutter, the app pairs an interactive map view with secure, account-based reporting.

Reports are geotagged so users can browse nearby listings, and the social-media-inspired feed keeps the community engaged with updates on each item's status — lost, found, or returned.

Authentication, storage, and real-time data are handled through Firebase, keeping the backend serverless and the app fast to ship.

Highlights

  • Interactive maps with geotagged lost-and-found reports
  • Secure Firebase authentication and real-time database
  • Community feed with item status tracking
